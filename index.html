health-coach

health-coach is a private, single-user tool. It reads the owner's own Google Health data (sleep, activity, heart metrics) with read-only access and sends the owner a daily summary in a private Telegram chat. It is not offered to other users.

Privacy policy

  • Data accessed: the owner's Google Health sleep, activity and fitness, health metrics and profile data, read-only.
  • Use: the data is used only to compute personal sleep, recovery and activity scores and to send those scores to the owner.
  • Storage: raw data is not stored. Only the generated daily message is delivered to the owner's private Telegram chat.
  • Sharing: data is never sold, shared with third parties, or used for advertising. If an optional AI summary is enabled, the computed scores are sent to the Anthropic API solely to write the owner's summary.
  • Revoking access: access can be revoked at any time at myaccount.google.com/permissions.

Google API Services usage complies with the Google API Services User Data Policy, including the Limited Use requirements.
